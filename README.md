# Salesforce AI Assistant

**Slack bot integrating Salesforce CRM with Claude AI for intelligent 
opportunity analysis and deal action execution.**

## Features

✨ **Intelligent Deal Analysis**
- Deal scoring (likelihood to close)
- Risk assessment & mitigation strategies
- Actionable next steps
- Customized winning strategies

🔗 **Salesforce Integration**
- Real-time opportunity data from Salesforce
- OAuth 2.0 authentication
- Bidirectional sync (read & write)

⚡ **Slack-First Experience**
- Mention @sales-assistant in Slack
- Get instant AI analysis
- Create tasks, update notes, schedule follow-ups
- All without leaving Slack
